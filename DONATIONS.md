# Donations

This project is free software and will stay free.

**Pledge:** donations made to this project are intended to fund **research into
glossectomy and oral/tongue cancer, with a focus on restoring and improving speech**,
including work that makes this software better for the people who use it.

To keep that pledge trustworthy, before accepting any money the maintainers should:

- [ ] Set up a transparent fiscal host (e.g. Open Collective, or a registered nonprofit or
      charitable trust in the maintainers' jurisdiction). Every incoming and outgoing
      payment should be publicly visible.
- [ ] Name the recipient research institutions or grant programmes, or define the process
      for choosing them.
- [ ] Publish a yearly report of what was received and where it went.
- [ ] Add a `.github/FUNDING.yml` that points to the fiscal host.

No donation channel exists yet. Until one does, please do not send money to anyone
claiming to collect for this project.
